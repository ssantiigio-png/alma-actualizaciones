# ALMA — versiones para descargar

Este repositorio solo tiene el programa listo para usar (`Alma.exe`) y `version.json`, que ALMA consulta
desde **Opciones → Buscar actualización** (y una vez por día al abrirse). ALMA nunca se actualiza sin preguntar,
y comprueba la huella SHA-256 del archivo antes de usarlo.

**Descarga directa:** [Alma.exe](https://raw.githubusercontent.com/ssantiigio-png/alma-actualizaciones/main/Alma.exe)
— no hace falta instalar nada: doble clic y listo.

El código fuente es privado.
